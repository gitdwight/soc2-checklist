# SOC 2 Type II Readiness Checklist

[![Live Demo](https://img.shields.io/badge/Live%20Demo-GitHub%20Pages-orange)](https://gitdwight.github.io/soc2-checklist/)

[![Latest Release](https://img.shields.io/github/v/release/gitdwight/soc2-checklist)](https://github.com/gitdwight/soc2-checklist/releases)

![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow)

A lightweight SOC 2 Type II readiness checklist for tracking common recurring compliance activities.

## Features

- Common SOC 2 operational activities
- Activity cadence
- SOC 2 Trust Services Criteria references
- Interactive checklist
- Persistent progress using browser localStorage
- Automatic readiness score
- Responsive dark-mode interface

## Example Activities

- Risk assessments
- Access reviews
- Penetration testing
- Vulnerability management
- Incident response tabletop exercises
- Business continuity testing
- Vendor reviews
- Security awareness training

## Disclaimer

This project is intended as a readiness aid and educational resource. SOC 2 requirements vary based on organizational scope, controls, commitments, applicable Trust Services Criteria, and auditor expectations.
