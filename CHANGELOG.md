# Changelog

All notable changes to this project will be documented here.

## v1.0.0

### Added

- SOC 2 Type II readiness checklist
- Governance, access management, security testing, incident response, monitoring, and key document categories
- Interactive completion tracking
- Automatic readiness score
- Browser localStorage persistence
- Organization field
- Prepared By field
- Print / Save as PDF capability
- Reset Form capability
- Responsive interface

### Changed

- Updated checklist content based on reviewed SOC 2 readiness activities
- Simplified checklist metadata to focus on operational cadence
